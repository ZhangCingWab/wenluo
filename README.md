# 文洛 · 文章竞赛社区

一个仿洛谷风格的文章/论坛/比赛社区，包含后台审核功能。

## 功能特点

- 多账号系统
- 文章与帖子审核
- 比赛创建与报名
- 文件投稿
- 排行榜
- 题库练习

## 技术栈

- Node.js + Express
- 会话管理
- 文件上传
- JSON 数据库

## 本地运行

```bash
npm install
npm start
```

访问 http://localhost:3000

## 部署

本项目支持多种平台部署：
- Glitch
- Railway
- Render
- 其他 Node.js 托管平台
